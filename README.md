# API-Flags
APIflags adalah aplikasi Android berbasis Kotlin dan ConstraintLayout yang menampilkan daftar negara beserta bendera, kode iso2, dan iso3. Data diambil dari API countriesnow.space memakai Retrofit, lalu bendera SVG ditampilkan dengan Coil. Pengguna bisa mencari negara lewat kolom pencarian dan membuka halaman detail dengan bendera besar.
